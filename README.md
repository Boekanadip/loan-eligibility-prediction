# 🏦 Loan Approval Classification using Machine Learning

> Sistem prediksi persetujuan pinjaman menggunakan Machine Learning untuk membantu proses screening awal pengajuan kredit berdasarkan karakteristik pemohon.
---

# 📌 Project Overview

Proyek ini bertujuan membangun model **Machine Learning** untuk memprediksi apakah pengajuan pinjaman seorang nasabah berpotensi disetujui atau tidak berdasarkan karakteristik pelanggan.

Selain membangun model klasifikasi, proyek ini juga mencakup proses **Data Understanding**, **Exploratory Data Analysis (EDA)**, **Data Cleaning**, **Feature Engineering**, **Model Building**, hingga **Model Evaluation**.

Proyek ini dikembangkan sebagai bagian dari portofolio **Data Science** untuk menunjukkan kemampuan dalam menyelesaikan studi kasus yang umum ditemui pada industri perbankan dan financial technology.

---

# 🎯 Objectives

- Memahami karakteristik data pemohon pinjaman.
- Melakukan Exploratory Data Analysis (EDA).
- Membersihkan dan mempersiapkan data sebelum pemodelan.
- Membangun model Machine Learning untuk prediksi persetujuan pinjaman.
- Mengevaluasi performa model menggunakan berbagai metrik klasifikasi.
- Memberikan insight yang dapat mendukung proses pengambilan keputusan.

---

# 📂 Dataset

Dataset yang digunakan merupakan dataset publik dari Kaggle:

**Loan Approval Classification Dataset**

https://www.kaggle.com/datasets/taweilo/loan-approval-classification-data

Dataset berisi informasi mengenai karakteristik pemohon pinjaman, seperti:

- Person Age
- Person Income
- Home Ownership
- Employment Length
- Loan Intent
- Loan Grade
- Loan Amount
- Interest Rate
- Credit History Length
- Previous Default
- Loan Status (Target)

# 💡 Business Insight

Beberapa insight yang diperoleh dari hasil analisis antara lain:

- Karakteristik pemohon memiliki pengaruh terhadap peluang persetujuan pinjaman.
- Variabel seperti pendapatan, jumlah pinjaman, dan riwayat kredit menjadi faktor penting dalam proses klasifikasi.
- Model dapat digunakan sebagai alat pendukung keputusan (*Decision Support System*) pada proses screening awal pengajuan pinjaman.
- Pendekatan berbasis data dapat membantu meningkatkan efisiensi proses evaluasi kredit.
